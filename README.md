# 自行車廠務部自動化與數據驅動管理系統

本倉庫為自行車廠務部主管日常工作自動化與數據驅動管理專案，旨在解決日常排程、訂單彙整與生產進度回報的手工痛點。

## 一、 工作中的重複、手工與容易出錯之處（Pain Points）

1. **多客戶訂單彙整與規格確認（容易漏看規格變更）**
   * **狀況**：業務或客戶傳送大量分散的訂單檔案，且常有版本異動，需人工逐筆核對管徑、零件與數量。
   * **錯漏**：人工複製貼上容易漏單、看錯規格或版本錯置，導致車架焊接錯誤或零件備錯。
2. **現場生產日報與排程進度核對（耗時且落後）**
   * **狀況**：每日需人工將現場生產數量回報與排程工單進行比對，計算達成率。
   * **錯漏**：手動加總計算繁瑣，若產線回報延遲或數字登錄錯誤，算出來的預估交期就不準，回報業務時容易被客訴。
3. **出貨盤點與交期回報（跨表手動比對）**
   * **狀況**：比對庫存與訂單需求來決定交期。
   * **錯漏**：手動比對多張表格效率極低，動態變更時常出錯。

## 四、 每個項目的 AI 與 人工分工規劃

### 項目 1：客戶訂單自動彙整與交期試算
* **【AI 做】**：
  1. 編寫 Python 程式碼，自動掃描並解析客戶訂單與生產日報。
  2. 自動計算各訂單之累計生產數量、達成率與預估交期。
  3. 產出結構化的彙整報表。
* **【人做】**：
  1. 確認程式產出的邏輯與廠務實際排程計算規則相符。
  2. 依實際管理需求調整交期緩衝天數參數。
* **【簽名】**：
  * AI 執行者：`opencode (Gemini 3.5 Flash Lite)`
  * 業務審核者：`廠務部主管`
